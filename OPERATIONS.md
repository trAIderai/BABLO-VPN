**Зачем московский узел.** SIP-провайдер с 01.09.2026 отбивает регистрацию с нероссийских
адресов (`SIP/2.0 403 IP not in whitelist`), из-за чего CloudSoftphone на iPhone не мог звонить
в Россию из-за границы. Московский выход это чинит. Реквизиты PBX — в `ru-server/pbx.env`
(под `.gitignore`), проверка адреса — `ru-server/sip-probe.py`.

**Клиенты используют приложение AmneziaVPN.** Обычный WireGuard к AmneziaWG не подключается —
это разные протоколы на уровне пакетов, и клиент не покажет внятной ошибки, просто не будет
хендшейка.

## Доступ

```bash
ssh -i ~/.ssh/id_ed25519 root@85.137.164.66     # Прага
ssh -i ~/.ssh/id_ed25519 root@185.130.249.179   # Москва
```

⚠ **Вход по паролю отключён на обоих**, только по ключу. Вернуть пароль:

```bash
rm /etc/ssh/sshd_config.d/00-hardening.conf && systemctl reload ssh
```

Имя файла обязано начинаться с `00-`: в OpenSSH выигрывает ПЕРВОЕ значение, а
`50-cloud-init.conf` задаёт `PasswordAuthentication yes`. Независимый запасной путь, не
зависящий от sshd, — **VNC-консоль в панели SmartApe**.

⚠ **Алиасы из `~/.ssh/config` читаются через раз** (кириллица в пути `$HOME` на рабочей
машине). Надёжнее явные опции, как выше.

**Админка 3x-ui** больше не смотрит в интернет — только `127.0.0.1:2053`:

```bash
ssh -L 2053:127.0.0.1:2053 root@85.137.164.66    # затем http://127.0.0.1:2053
```

## Типовые задачи

**Добавить клиента.** Через панель (`https://vpn.bablo.bot` или `https://rvpn.bablo.bot`) —
кнопка «Добавить», дальше QR или `.conf`. На Москве есть и скрипт: `bash add-client.sh <имя>`.
Каждому человеку — отдельный клиент, иначе устройства выбивают друг друга.

**Сменить метку узла или кнопку перехода.** Правка `.env` и пересоздание, без пересборки:

```bash
cd /opt/bablo-vpn && nano .env        # NODE_LABEL, NODE_INDEX, PEER_URL, PEER_LABEL
docker compose up -d --force-recreate --no-deps vpn-ui
```

`NODE_INDEX` задаёт позицию в переключателе (0 — слева, 1 — справа) и специально не выводится
из текста: иначе каждая панель ставила бы себя первой.

**Пересобрать витрину (vpn-ui).** ⚠ **Только на Москве.** У Праги ~200 МБ свободной памяти при
14 контейнерах с почтой — сборка Next.js вытолкает их в swap и подставит под OOM-killer.
Порядок: собрать на Москве → перенести образ (~51 МБ) → пересоздать контейнер на Праге.

```bash
# на Москве
docker compose build vpn-ui && docker compose up -d --force-recreate --no-deps vpn-ui
# перенос
ssh root@185.130.249.179 "docker save bablo-vpn-vpn-ui:latest | gzip -6" > img.tgz
cat img.tgz | ssh root@85.137.164.66 "gunzip | docker load"
ssh root@85.137.164.66 "cd /opt/bablo-vpn && docker compose up -d --force-recreate --no-deps vpn-ui"
```

Перед подменой сохранять прежний образ: `docker tag bablo-vpn-vpn-ui:latest bablo-vpn-vpn-ui:backup-ГГГГММДД`.

**Сменить пароль AdGuard** — раздел «AdGuard Home» в [`README.md`](README.md).

## Грабли, которые уже стоили времени

★★★ **`docker start adguard-home` после правки конфига НЕ работает.** Контейнер живёт в сетевом
пространстве `wg-easy` и хранит его ID; остановка заставляет docker перепроверить ссылку, она
оказывается устаревшей — `joining network namespace of container: No such container`. Нужен
`docker compose up -d --force-recreate --no-deps adguard-home`. Пока он лежит, у клиентов Праги
**нет DNS** — `WG_DEFAULT_DNS=10.8.0.1` указывает именно на него.

★★★ **musl-`awg` для контейнера собирать, а не копировать с другого сервера.** В Праге
`amneziawg-tools` на `apt-mark hold` и версия старая; на свежем модуле ядра это даёт
`awg setconf: Unable to modify interface: Invalid argument` и контейнер в цикле перезапуска.
Рецепт сборки — в `ru-server/README.md`.

★★ **Перед перезагрузкой проверять `dkms status`** — собран ли модуль AmneziaWG под новое ядро.
Обычно DKMS делает это сам при установке ядра, но убедиться дешевле, чем поднимать VPN из VNC.

★★ **Проверять Caddy правильно.** `curl -k https://127.0.0.1/ -H 'Host: домен'` возвращает `000`:
SNI уходит как `127.0.0.1`, сертификата на него нет. Правильно —
`curl --resolve домен:443:127.0.0.1 https://домен/`. Эта ложная тревога уже вызвала один
ненужный откат.

★★ **Мобильная вёрстка: `overflow-x: hidden` стоит на `html, body`.** Поэтому слишком широкая
строка не даёт прокрутки, а обрезается — и, поскольку контейнер центрирован (`margin: 0 auto`),
обрезается **сразу с двух сторон**: слева срезает логотип, справа кнопки. Если страница
«съехала» — искать элемент, который не умеет переноситься или сжиматься (`min-width: 0`).

★ **Премису из хэндоффа перепроверять замером.** В этой работе три моих вывода до замера
оказались неверными: блок SIP считал HTTP-уровнем (оказался SIP), приписал регистрацию облаку
Acrobits (телефон регистрируется напрямую), объявил утёкший VLESS UUID действующим (в базе 3x-ui
его нет вовсе).

## Безопасность

- Репозиторий **публичный**. История переписана 2026-09-03 (`git filter-repo`), вычищены пароль
  админки, bcrypt-хэш AdGuard, два UUID VLESS. Все они к тому моменту были ротированы или мертвы.
- Включить хук после клонирования: `git config core.hooksPath .githooks`.
- Боевые значения живут в `.env`, `adguard/AdGuardHome.yaml`, `ru-server/pbx.env` — все под
  `.gitignore`, в репозитории только образцы `*.example`.
- На обоих узлах: fail2ban, вход только по ключу, журнал ограничен 500 МБ, логи docker 10 МБ×3.

## Открытые вопросы

1. **Входящие звонки при заблокированном экране iPhone** — исходящие подтверждены, входящие
   отдельно не проверялись. Если не доходят — смотреть в сторону push и того, держит ли iOS
   туннель в фоне.
2. **Пароли обеих панелей совпадают.** Компрометация одной открывает вторую.
3. **Пользуется ли кто-то Xray/Hysteria2.** Счётчик показывает 3.79 ГБ у клиента `CZ`, но он
   накопительный и может быть с весны. Способ проверить: обнулить счётчики и посмотреть через
   несколько дней. Если тишина — отключение закроет три порта в интернет, освободит ~60 МБ
   памяти и уберёт главного производителя логов.
4. **ТСПУ на плече Казахстан → Россия** пока пропускает AmneziaWG. Если начнёт резать — вторым
   протоколом включать Hysteria2 (UDP/QUIC), но не VLESS: TCP-туннель портит голос.
